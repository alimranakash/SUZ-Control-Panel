A central dashboard to manage SUZ-related plugins & features in WordPress and WooCommerce.

== Description ==

**SUZ Control Panel** is a central dashboard plugin to manage SUZ-related features, settings, and WooCommerce integrations.  
With this plugin, you can control registrations, manage custom roles, view debug logs, and much more — all from one unified interface.

**Key Features:**
- Central dashboard for SUZ plugins and settings.
- IČO Verification Tracker.
- Ticket Control management (frontend + backend support).
- WooCommerce checkout process control.
- Role manager and profile completion enforcement.
- Logger system for tracking important events.
- Admin notifications for important updates.
- Easy integration with Eventin WooCommerce combo.

**Use Cases:**
- Managing SUZ-specific workflow.
- Controlling user registrations & profiles.
- Monitoring system activities from a single place.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/suz-control-panel` directory, or install the plugin through the WordPress plugin screen directly.
2. Activate the plugin through the ‘Plugins’ screen in WordPress.
3. Navigate to **SUZ Control Panel** in the WordPress admin menu.
4. Configure the settings as needed.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =
Some features (e.g., WooCommerce checkout control) require WooCommerce, but the plugin works without it for other admin tools.

= Can I use the Ticket Control feature on the frontend? =
Yes. The Ticket Control system is built to work on both frontend and backend.

= Is the plugin translation-ready? =
Yes, all strings are translatable. Text domain: `suz-control-panel`.
